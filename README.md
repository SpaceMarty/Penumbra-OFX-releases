# Penumbra OFX

Installers for **Penumbra Texture**, the Penumbra OpenFX effects for DaVinci Resolve:
**Penumbra Blend** and **Penumbra Detail**. In Resolve they are in the Color page's OpenFX
library, under Penumbra Texture (under Penumbra up to 0.5.0).

Each release carries one installer per platform — a `.pkg` for macOS and an `.msi` for
Windows — and `SHA256SUMS.txt` over everything it publishes. Quit DaVinci Resolve before
installing.

Renders carry a watermark until a licence is activated, from the Licence button at the foot
of either effect's panel. Product pages and support: [penumbra.tools](https://penumbra.tools).
